Tabs

.tabs is a row of buttons with data-value over panels with a matching data-tab. Dash.tabs(el, { value, store, hash, panels, onChange }) shows the chosen panel and hides the others; arrow keys move between tabs. store remembers the tab, hash: 'view' keeps it in the address (#view=list) so a link or a reload opens it, and panels says where the panels are when a page has two sets. It returns { value, set(v) }. A .count-badge in a tab holds a count.

Breadcrumbs

Dash.crumbs(items, { label }) writes where the reader is: { label, href } for each level, and plain text for the last, which is marked aria-current="page". A link that would run script becomes #. It's a nav named "Breadcrumb" with an ol, so screen readers announce it as a trail.

Steps

Dash.stepper(steps, current, { vertical, tone, label }) shows the steps of a task: those before current are done (a tick), the current one is marked aria-current="step", and a step { failed: true } is red, with a "!". Screen readers hear "done" and "failed" with the names. A step is text or { label, sub, failed }; current past the last means all are done. On a phone only the current step's name shows, and the others are still read out. vertical: true stacks them, with the sub line under each name.

Pages of rows

Dash.paginate(rows, page, perPage) cuts one page out of the rows and says where it is ({ rows, page, pages, total, from, to, perPage }). Dash.pager(that, { noun, sizes }) writes the bar under a table: "21–40 of 140 servers", a rows-per-page select (data-per-page) and page buttons (data-page). Dash.pageItems(page, pages) is the list of page numbers it shows, with gaps. Dash.table does all of this itself.

    Timelines

    Dash.timeline(items, { empty }) lists events on a line, newest first as given, each with a dot in its tone: { title, time, text, tone }. A time that Dash.time can read shows as "12 min ago" and keeps itself current; other text shows as it is.
