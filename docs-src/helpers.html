The basics

The builders return HTML strings with every value escaped; put them in with Dash.render (or innerHTML), and handle clicks with one listener on a parent. Times are milliseconds. A missing number prints as —.

CallWhat it does
Dash.$(id)The element with that id.
Dash.esc(text)Text made safe to put in HTML (<, &, quotes).
Dash.on(parent, type, selector, fn)One listener on a parent for events on matching children: fn(event, matched). It keeps working when the children are redrawn.
Dash.isNum(v)True for a finite number, or text that is one ('3'); false for blanks, null and booleans.
Dash.versionThe kit's version, as in the first line of both files.

Redrawing without losing the reader's place

Dash.render(el, html, { force }) puts new HTML into a part of the page that refreshes. It skips the write when nothing changed, and while the reader is selecting text there. When it writes, it keeps the focused control (and what's typed in it, and the caret), which <details> are open, and how far inner boxes are scrolled. Elements are matched by id, else data-key. Times

Dash.time(x, { seconds }) turns what a server sends into milliseconds: milliseconds, a Date, ISO text (no zone means UTC), an HTTP date, or seconds with seconds: true; anything else is NaN. Dash.ago(t) and Dash.until(t) write a <time> that keeps itself current ("12 min ago", "in 3h 5m"; every 15 s), with the full time as its tooltip.
CallGives
Dash.fmt.dur(ms), .span(ms)3h 5m; 2.7 h
Dash.fmt.ago(t), .until(t)just now, 40 s ago, 12 min ago, 2.5 h ago, 3 d ago; in 3h 5m, now (text, not kept current)
Dash.fmt.date(t, { utc }), .time(t, { seconds, utc })Nov 21 (Nov 21, 2025 in another year); 14:05:09. Both read t as Dash.time does.
Dash.fmt.clock(t), .when(t), .utc(t)14:05; Nov 21, 14:05; Nov 21, 02:22 UTC

Fetching and polling

  • Dash.api(url, { method, json, etag, headers }) fetches JSON. An error carries .status and the server's { error } text. A 401 goes to Dash.config.loginUrl when it's set. etag: true reuses the last answer on a 304.
  • Dash.poll(fn, ms, { hiddenMs, live, staleAfter }) runs fn now and every ms, one run at a time, slower while the tab is hidden (hiddenMs) and again as soon as it's visible. live is the id of a .live status it keeps right (stale after staleAfter, three times ms). It returns { now(), stop() }.
  • Dash.socket(path, { onMessage, onState, retryMs }) is a WebSocket that reconnects; a close with code 1008 goes to the sign-in page.
Dash.poll(async () => {
  const servers = await Dash.api('/api/servers', { etag: true });
  table.update(servers);
}, 15000, { live: 'live' });

Remembering things

  • Dash.store.get(key, fallback) and .set(key, value): JSON in the browser's storage that never throws (a private window, blocked storage: you get the fallback).
  • Dash.hash: the part of the address after # as settings, #view=list&id=7. .get(key), .set({ key: value }, { push }) (null removes a key; push adds a history entry), .on(fn) when it changes, .parse(text) and .format(object).
  • Dash.config: loginUrl (null), themeKey ('dash.theme'), sideKey ('dash.side'), privacyKey ('dash.private', for hidden values) and csp (false; see strict style policies).

Shortcuts and matching

Dash.key(combo, fn, { inInputs }) adds a keyboard shortcut ('/', 'g', 'mod+k', 'shift+?') that stays quiet while the reader types in a box, and returns a function that removes it. Dash.match(row, query, fields) is true when every word of the query is in one of the row's fields, in any case: the search behind Dash.table's filters and the suggestions.
