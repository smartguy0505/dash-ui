Logs

Dash.log(el, { lines, height, max, time, wrap, label }) shows lines as they come. .add(x) takes a text (several lines are several), a line { time, level, source, text }, or a list of them. It stays at the end until the reader scrolls up; then it stays where it is, and a button says how many lines are new. max (2000) is how many it keeps: the oldest go, without moving what is being read. A warn or an error has its colour; the colours a terminal shows (ANSI) are kept, and the rest of its codes left out.

tools: true (.log-tools) puts a filter, Wrap, Copy and Clear above it. From code: .filter(text or test), .wrap(on), .clear(), .end(), .text (what the filter leaves, to copy), .lines, .count ({ shown, total }). It isn't read out as it comes, unless live: true says so.

JSON

Dash.json(el, value, { open, copy, label }) shows what a value is made of, to open and close. open is how many levels are open at first (1; true is all of them, up to a few thousand rows). A branch is drawn when it opens and a long list comes in hundreds, so a big answer costs nothing until it is looked at. Maps, sets, dates and what holds itself are fine. .set(value) shows another, .open(levels) opens or closes.

Dash.json.html(value, { open, max }) is the same as HTML, all of it, at most max rows (1000): for a page a server writes, or a row that opens.
