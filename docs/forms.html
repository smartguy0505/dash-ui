Inputs

.input styles a text box, a select and a textarea alike. .input.mono is for addresses and ids; .input.sm and .input.lg change its size. textarea.input.autosize grows as it's typed into, up to --max-h (320 px), where the browser supports field-sizing (elsewhere it keeps its size).

Fields

.field stacks a label, the input, then a .hint or an .err. .field.invalid turns it red; set aria-invalid="true" on the input as well, and point aria-describedby at the message. .field-label is the same label for a group that isn't one input (a row of choices).

Search boxes

.search wraps an input with an icon and an optional .count. Dash.search(input, { onChange, debounce, key, store }) calls onChange(query) once typing pauses; Escape clears it, / jumps to it, and .count(shown, total) fills the count. With store the last query comes back on the next visit.

Selects

Wrap a <select class="input"> in .select to give it the kit's arrow in place of the browser's. Inside a .field it is full width.

Input groups

.input-group joins an input to text and buttons around it: .affix for a unit or a prefix, .btn for an action, and a .select too.

Checkboxes and radios

.checkline is a checkbox or radio with its label. .checks stacks a few, and .checks.across puts them on one line. Give the group a name: role="group" (or radiogroup) and an aria-label, or a fieldset with a legend.

Choices as cards

.choices makes radios (or checkboxes) into cards: each a label.choice holding the input, then a .choice-body with a b and a .hint. The checked one is outlined in its tone (blue by default). --choice-min (200 px) is how narrow a card gets before they stack.

Switches

.switch is a checkbox drawn as a switch, for a setting that applies at once: <label class="switch"><input type="checkbox"><span class="track"></span> Label</label>. A tone colours it on.

Sliders

Dash.slider({ label, name, min, max, step, value, unit, tone, disabled }) writes a range input with its value beside it, and dash.js keeps the value current as it moves. By hand: <label class="slider"><span>Volume</span><input type="range" data-unit="%"><output>50%</output></label>. Inside a .field its name reads as the field's label.

Dropping files

.dropzone is a <label> around an input type="file", so a click chooses files, and files dropped on it go into the input (only the kinds its accept allows), with input and change events as if they had been chosen. The chosen names show in its .files; .over marks it while files are dragged over.

Suggestions

Dash.combobox(input, { options, onPick }) gives a text box a list of suggestions that narrows as the reader types. Arrow keys move through it, Enter or a click picks, Escape closes the list (only the list, inside a dialog too), and the box keeps the focus throughout. The typed words are bold in each suggestion.

  • options: strings, or { value, label, sub } (sub is a second, quieter part), or a function (query) => list or a promise of one, for a server search. Answers that arrive after the reader typed on are dropped. debounce (150 ms) is how long typing has to pause first.
  • strict: true: on leaving, text that is no suggestion is put back to the last pick (or emptied); a box the reader empties stays empty.
  • max (50) suggestions, minChars before any show, empty for the line when none match.
  • It returns { value, set(value), close(), destroy() }; value is the picked option while the box still shows it, else null. It's an ARIA combobox: the box has role="combobox", the list listbox, the active suggestion aria-activedescendant.

Dates

Dash.datepicker(input, { min, max, onPick, firstDay }) puts a calendar button in a date box. Dates are YYYY-MM-DD, what <input type="date"> sends. The calendar opens on the box's date (or today): arrows move a day or a week, Home and End go to the week's ends, PageUp and PageDown a month (with Shift, a year), Enter picks and Escape closes. Days before min or after max can't be picked. Typing works too: a short date like 2026-3-7 is written out, and one that doesn't exist is marked aria-invalid. Weeks start on Monday; firstDay: 0 starts them on Sunday. Month and day names are in the reader's language.

It returns { value, set(day), open(), close(), destroy() }; value is the box's date if it's a real one in range, or null.
