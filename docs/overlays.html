Asking a question

Three helpers cover most questions, each a promise of the answer. Dash.confirm(text, { title, ok, cancel, tone, anchor }) is yes or no (Cancel has the focus; tone: 'bad' makes the button red; anchor asks in a popup beside that button instead). Dash.ask(title, { value, placeholder, type, required }) asks for one line of text, or null. Dash.alert(text, { title, ok, tone }) is a message with one button.

Dash.dialog({ title, text, body, actions, cancel, drawer, focus, rules }) is a dialog made on the spot, for a small form: it resolves { value, fields }, where fields are the named inputs in body and value is null when cancelled.

Modals

Dash.modal(options) is for more than a question: a form that saves, details that keep updating, a long list. It returns a handle you keep.

  • title, text (a line under it), body (HTML or an element), cancel (a ghost button's label), actions: { label, value, primary, tone }.
  • size: sm (400 px), md (560), lg (760), xl (1040) or full. drawer: true slides it in from the right, full height.
  • onAction(value, modal) runs on a button; the button is busy until it's done. An error it throws shows in the foot (.modal-error) and keeps the modal open, and so does returning false.
  • Enter in a field presses the primary action, after the fields' own checks (required, type="email"). Your own buttons in the body need type="button".
  • dismissable: false: no ×, and Escape and clicks outside do nothing, for something that must finish.
  • The handle: .el, .body (the part that scrolls), .fields(), .update({ title, text, body, actions }) (redrawn like Dash.render, so typing isn't lost), .error(text), .close(value), and .closed, a promise of { value, fields } (value is null after ×, Cancel, Escape or a click outside).

Dialogs and drawers by hand

A <dialog class="dialog"> is centred, with a .dialog-body and .dialog-actions; a <dialog class="drawer"> slides in from the right, with a .drawer-head and a .drawer-body. Open either with el.showModal(). Anything with data-dismiss inside closes it, and so do Escape and a click on the backdrop.

Popups

Dash.popup(anchor, content, { placement, align, width, cls, label, focus, onClose }) is a box beside an element (or at a point: a right-click). It floats above everything, a sideways-scrolling table or an open dialog included, flips when there's no room and stays inside the window. It closes on a click outside, on Escape (the focus goes back to its button) or with .close(), and follows its button when the page scrolls or a refresh redraws it. Called again for the same button it closes, like a toggle.

  • content: HTML, an element, or a function (popup) => …. placement: bottom, top, right or left; align: start, center or end. focus: true (or a selector) puts the focus inside.
  • Inside: .popup-title, .popup-text and .popup-actions give a small note or question its shape.
  • The handle: .el, .close(value), .update(content), .place() and .closed.
  • No code: data-popup="id" on a button opens the content of <template id="id"> (or of any element with that id).
  • Dash.place(rect, size, view, { placement, align, offset }) is the placing it uses, for a box of your own.

Menus

Dash.menu(anchor, items, { placement, align, label }) is a menu beside a button, or at the pointer for a right-click, and resolves to the chosen value (or null). An item is a string or { label, value, hint, tone, disabled, checked, href }; '-' is a line and { heading } a small label. It moves with the arrow keys, Home, End and first letters; Enter picks, Tab and Escape leave.

Tooltips

data-tooltip="text" shows a tooltip on hover and on keyboard focus, kept inside the window, in an open dialog or popup too. Use it for a word or a line; a title is enough for long text.
