Labels and badges

Status pills, tags, chips, changes, ranks, avatars and badges.

Status pillsTagsChipsChanges and ranksAvatarsBadges

Status pills

.pill is a state, in a tone, usually with a .dot. .dot.pulse pulses, for something happening now; .dot.hollow is a ring, for something waiting. .pill.lg is bigger, and a .n inside holds a count in even digits. Dash.pill(text, tone) writes one with its dot.

Tags

.tag is a small fact: a region, a version, a plan. It is tinted in its tone; .tag.plain is neutral and .tag.outline a ring. Put several in .tags. Dash.tag(text, tone) writes one.

Chips

.chip is a pill with a border. A button.chip with aria-pressed is a choice (a filter), and Dash.seg can run a row of them as one choice. .chips wraps them; .chips.scroll keeps them on one line that scrolls sideways.

Changes and ranks

.chg is a signed change, green up and red down (.up, .down, .flat). Dash.chg(value, text) picks the class from the sign; { eps } is how small a change still counts as flat. .rank is "#2 of 14", gold, silver and bronze for the top three; Dash.rank(position, of) writes it.

Avatars

Dash.avatar(name) is the name's initials in a colour picked from the name, so the same person always has the same colour. { src } shows a picture instead (a data:image/ one too), { tone } picks the colour, { size: 'sm' | 'lg' } and { square: true } change its shape. Dash.avatars(people, { max }) overlaps a few and counts the rest as "+3"; every name is in its label and tooltip.

By hand: <span class="avatar purple" role="img" aria-label="Ada Lovelace">AL</span>, or an <img> inside it.

Badges

data-badge="3" on a button or an icon puts a count in its corner, and data-badge="" a dot. --badge changes its colour (red by default). The badge is drawn, not read: say the count in the button's aria-label too. .count-badge is a count beside a word, in a tab or a sidebar heading.
