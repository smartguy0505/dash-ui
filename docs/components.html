Start

All components

Every component in the kit, by its class.

Page layout 5

The top bar, the page, grids, rows, the phone navigation, and panes that can be resized.

The top bar
.topbar stays at the top while the page scrolls.
The page
.page holds the content, centred, up to --page-max wide (1320 px; .page.wide 1480, .page.narrow 1000).
Grids, stacks and rows
For anything else, the layout utilities give flex and grid with widths: grid grid-cols-1 md:grid-cols-3 gap-4.
On a phone
.bottom-nav is a row of links along the bottom of a phone (640 px down; hidden wider).
Panes
Parts side by side with a bar between them that can be moved. data-panes is enough (its value is where the sizes are remembered); data-sizes are the sizes to start from, data-min the least a pane can be, in pixels, and data-vertical puts one above the other.

Buttons 7

Buttons, icon buttons, links, segmented controls, menus, the floating button and spinners.

Buttons
.btn is a plain button.
Busy buttons and spinners
Dash.busy(button, work) disables the button and puts a spinner before its label until work (a function or a promise) is done, and returns its result.
Icon buttons
.icon-btn is a 28 px square button for an icon.
Buttons that look like links
.link is a button styled as a link, for an action inside text ("Show all"); .link.quiet is muted until hovered.
Segmented controls
.seg is a row of buttons where one is chosen.
Menus without code
A <details class="menu"> with a summary (styled as a button) and a .menu-list of buttons and links is a menu with no script of your own.
Copy buttons
Any button with data-copy="text" copies the text when pressed, shows "Copied" in a toast (not with data-quiet) and says so on itself for a moment (.copied).

Forms 11

Inputs, fields, selects, input groups, checkboxes and radios, choices, switches, sliders, file drops, and saying what is wrong.

Inputs
.input styles a text box, a select and a textarea alike.
Fields
.field stacks a label, the input, then a .hint or an .err.
Search boxes
.search wraps an input with an icon and an optional .count.
Selects
Wrap a <select class="input"> in .select to give it the kit's arrow in place of the browser's.
Input groups
.input-group joins an input to text and buttons around it.
Checkboxes and radios
.checkline is a checkbox or radio with its label.
Choices as cards
.choices makes radios (or checkboxes) into cards: each a label.choice holding the input, then a .choice-body with a b and a .hint.
Switches
.switch is a checkbox drawn as a switch, for a setting that applies at once: <label class="switch"><input type="checkbox"><span class="track"></span> Label</label>.
Sliders
Dash.slider({ label, name, min, max, step, value, unit, tone, disabled }) writes a range input with its value beside it, and dash.js keeps the value current as it moves.
Dropping files
.dropzone is a <label> around an input type="file", so a click chooses files, and files dropped on it go into the input (only the kinds its accept allows), with input and change events as if they had been chosen.
Checking a form
Dash.form(form, { rules, onSubmit }) says what is wrong under each field, instead of the browser’s bubbles.

Richer fields 10

Numbers with − and +, passwords that can be shown, codes, suggestions, tags, selects that can be searched, dates, ranges, ratings, and text that is edited in place.

Numbers with − and +
Dash.number({ label, name, min, max, step, value, unit, hint, required }) writes a number box with a button on each side.
Passwords that can be shown
A button with data-peek beside a password box shows what is typed, and hides it again when pressed once more or when the form goes out.
Codes
Dash.code({ label, name, length, letters, submit }) is a box for the code from a message, drawn as one box per character.
Suggestions
Dash.combobox(input, { options, onPick }) gives a text box a list of suggestions that narrows as the reader types.
Tags
Dash.tagbox(input, { options, max, strict, allow, onChange }) makes a text box take several things.
Selects that can be searched
Dash.multi(select, { noun, placeholder, search }) puts a button over a <select> that says what is picked and opens a list: boxes to tick for a <select multiple>, one to pick otherwise, with its <optgroup>s as headings and a search box from eight options on.
Dates
Dash.datepicker(input, { min, max, onPick, firstDay }) puts a calendar button in a date box.
From and to
Dash.range({ label, name, min, max, step, from, to, unit }) is a slider with two ends, where neither passes the other.
Ratings
Dash.rating({ name, value, max, label }) is a group of radio buttons drawn as stars; a form sends the number.
Edit in place
Dash.inline(el, { value, label, onSave }) shows text that becomes a box when it is pressed.

Labels and badges 6

Status pills, tags, chips, changes, ranks, avatars and badges.

Status pills
.pill is a state, in a tone, usually with a .dot.
Tags
.tag is a small fact: a region, a version, a plan.
Chips
.chip is a pill with a border.
Changes and ranks
.chg is a signed change, green up and red down (.up, .down, .flat).
Avatars
Dash.avatar(name) is the name's initials in a colour picked from the name, so the same person always has the same colour. { src } shows a picture instead (a data:image/ one too), { tone } picks the colour, { size: 'sm' | 'lg' } and { square: true } change its shape.
Badges
data-badge="3" on a button or an icon puts a count in its corner, and data-badge="" a dot. --badge changes its colour (red by default).

Lists and trees 10

Lists to read, to pick from and to put in order, trees, facts and timelines.

Lists
Dash.entries(rows, options) is a list of things, a line or two each: a lead (an avatar or an icon), a title and sub, and an end (a time, a pill). title and sub are keys or functions and are escaped; lead and end return HTML. href: (row) => url makes each a link, button: true a button (with key as its data-key, for a click handler and so a redraw keeps the focus). wrap: true lets long text wrap instead of ending in …; empty is the text when there are no rows.
Lists to pick from
Dash.list(el, options) writes the same rows and looks after them.
Lists to put in order
reorder: true gives each row a grip.
Long lists
more: 20 shows twenty rows and a button for the next twenty. load(offset) gives the rows from there on, or a promise of them: the first part is asked for at once, each further one with the button, and the end is a part shorter than more.
Trees
Dash.tree(el, options) shows things inside things.
Trees to pick from
With select: 'one' a click picks a row, whether it is a branch or a leaf; the arrow in front of a branch, or a second click on it, opens and closes it. select: 'many' gives each row a box: ticking a branch ticks every leaf in it, also the ones that aren't shown, and a branch of which some is ticked has a dash. onSelect gets the row, or the ticked leaves. can(row) says which may be picked, selected what is at the start, and .select(keys) changes it.
Trees that load as they open
A row whose children are true has some that aren't there yet. load(row) gives them, or a promise of them, when it is first opened.
Boards
Dash.board(el, { columns, cards, column }) is cards in columns (a kanban board): column is the field of a card that says which one it is in.
Facts
.kv is a dl of names and values in columns (--cols, 2).
Timelines
Dash.timeline(items, { empty }) lists events on a line, newest first as given, each with a dot in its tone: { title, time, text, tone }.

Tables 7

Tables with sorting, row states, sticky headers, and rows that become cards on a phone.

A table from its columns
Dash.table(el, { columns, rows, sort, perPage, key, onRow, … }) draws a whole table: sortable headers, cells, a pager if asked, and cards on a phone.
Rows to pick
select: true puts a box on every row, one in the header, and a bar under the table while any are picked.
Rows that open
expand: (row, box) => markup gives each row a button that opens its details under it.
Tables by hand
A .table inside a .panel gets a rounded header strip; in a .table-wrap the table is its own card and scrolls sideways if it must.
Row states
.table.stack turns each row into a small card on a phone.
On a phone, and long tables
.table.stack turns each row into a small card on a phone.
Working with rows

Logs and data 2

Lines as they come, and a value to open and close.

Logs
Dash.log(el, { lines, height, max, time, wrap, label }) shows lines as they come.
JSON
Dash.json(el, value, { open, copy, label }) shows what a value is made of, to open and close. open is how many levels are open at first (1; true is all of them, up to a few thousand rows).

Charts and progress 13

Bars, meters, legends, column charts, donuts, gauges, sparklines, lanes, heatmaps, days and progress.

Bars
Dash.bar(frac, tone) is a bar filled to frac (0 to 1); .bar.thin is thinner and .bar.tinted has a tinted track.
Legends
Dash.legend(items, { list, button }) names the colours of a chart: each item { label, value, tone }, a swatch, the name and the value in b. list: true puts one per line (an item with 0 fades, .zero); button: true makes them buttons, for a legend that filters.
Horizontal bars
Dash.hbars(rows, { max, format, button }) is a list of bars with their names and values, for a top ten: each row { label, value, tone, text, key }. max sets the full length (the largest value otherwise), format writes the values. --hb-label and --hb-value set the two columns' widths.
Column charts
Dash.bars(points, { height, ticks, labelEvery, minorEvery, format, max, read }) is a column chart with a value axis.
Line charts
Dash.lines(el, series, options) draws values over time, one line per series, on one axis.
Donuts
Dash.donut(segments, { center, sub }) is a ring of { value, tone, label } segments with a number in the middle.
Gauges
Dash.gauge(frac, { name, sub, tone }) is a half-circle gauge.
Sparklines
Dash.spark(values, { tone, height, area, labels }) is a small line of a trend, with an area under it unless area: false, a dot on the last value, and labels under it (['24 h ago', 'now']).
Lanes
Dash.lanes(el, rows, { from, to, ticks, axis, nouns, labelWidth, empty }) draws what happened when, one lane per thing, over the last 24 hours unless from and to say otherwise.
Heatmaps
Dash.heatmap({ rows, cols, values, label, min, max, format, show, every, tone }) shows how much there is in a grid: a real table, with a shade per cell.
Days
Dash.days(points, { weeks, to, label, noun, tone, max, first }) is a square per day and a column per week, for the last 26 weeks unless weeks and to say otherwise.
Progress
Dash.progress(frac, { tone, label, value, lg, title }) is a progress bar with role="progressbar" and its value. label puts a line above it (.progress-head) with the share on the right, or value in its place ("6.2 of 10 GB"); lg: true is thicker.
Under a strict style policy
A page served with Content-Security-Policy: style-src 'self' drops every style="" in its markup, and the builders that size things (Dash.bar, meter, split, hbars, bars, lines, spark, progress) write sizes that way.

Panels and cards 8

Panels, cards, stat tiles, the big number, callouts, banners, accordions and dividers.

Panels
.panel is a section of a page: a card-coloured box with a border.
Cards
.card is one of many, in .cards (as many across as fit, each at least --card-min, 300 px).
Stat tiles
.stat is a number at a glance: a .label, a .value (with a small unit) and a one-line .note (.note.wrap may take two).
The big number
.hero is the one number a page is about, with what explains it beside it (it stacks on a phone).
Status banners
.banner is the page's status in one line with a big dot: a .badge (with an i inside), a .banner-title and a .banner-text.
Callouts and rings
.callout is a soft block for a note, tinted when it has a tone, with a .callout-title.
Accordions
.accordion joins <details> blocks into one box, with a chevron on each summary.
Dividers
.divider is a line between things, with a word in it if it has one.

Navigation 9

The sidebar with its groups and its drawer, the section being read, the command palette, tabs, breadcrumbs, steps and pages.

A sidebar
.shell puts a .sidebar beside the .content.
Groups in the sidebar
Dash.nav(el, items, { current, store, onPick }) writes a sidebar's links from data.
The sidebar as a drawer
Add .offcanvas to the shell and, from 900 px down, the sidebar becomes a drawer over the page.
Marking the section being read
Dash.spy(el, { offset, onChange }) follows the reader down a long page: of the links in el to parts of this page, the one to the part being read gets aria-current="location".
Command palette
Dash.palette({ items, key, recent, placeholder, onPick }) is a box to find anything and do it, from anywhere on the page: key opens it ('mod+k'.
Tabs
.tabs is a row of buttons with data-value over panels with a matching data-tab.
Breadcrumbs
Dash.crumbs(items, { label }) writes where the reader is: { label, href } for each level, and plain text for the last, which is marked aria-current="page".
Steps
Dash.stepper(steps, current, { vertical, tone, label }) shows the steps of a task: those before current are done (a tick), the current one is marked aria-current="step", and a step { failed: true } is red, with a "!".
Pages of rows
Dash.paginate(rows, page, perPage) cuts one page out of the rows and says where it is ({ rows, page, pages, total, from, to, perPage }).

Modals and popups 6

Modals, dialogs, drawers, questions, popups, menus and tooltips.

Asking a question
Three helpers cover most questions, each a promise of the answer.
Modals
Dash.modal(options) is for more than a question: a form that saves, details that keep updating, a long list.
Dialogs and drawers by hand
A <dialog class="dialog"> is centred, with a .dialog-body and .dialog-actions; a <dialog class="drawer"> slides in from the right, with a .drawer-head and a .drawer-body.
Popups
Dash.popup(anchor, content, { placement, align, width, cls, label, focus, onClose }) is a box beside an element (or at a point: a right-click).
Menus
Dash.menu(anchor, items, { placement, align, label }) is a menu beside a button, or at the pointer for a right-click, and resolves to the chosen value (or null).
Tooltips
data-tooltip="text" shows a tooltip on hover and on keyboard focus, kept inside the window, in an open dialog or popup too.

Feedback 5

Toasts, notices, the live status, flashes, empty states and loading lines.

Toasts
Dash.toast(message, { tone, ms, action, onAction }) is a short message at the bottom of the window that goes away on its own.
Notices
Dash.notify({ key, title, status, text, tone, onClick, ms, max }) is an alert in the corner that stays until it's closed (or for ms).
The live status
.live says whether the page's data is current: data-state is on, stale, off or connecting (its dot pulses).
Flashing a change
Dash.flash(el) (or the .flash class) briefly highlights a value that just changed, so the eye finds it.
Empty and loading
.empty is what a list shows with nothing in it: an .empty-title (or h2), a line, and a button.

Privacy and sign-in 3

Hiding amounts and addresses behind an eye, and the sign-in page.

Hidden values
An eye in the top bar lets the reader hide amounts, names or account numbers before a meeting or a screenshot.
Hidden addresses
Dash.maskIps(text) escapes the text and blurs each IPv4 address in it, so they stay out of screen shares; a click or Enter on one shows every copy of that address on the page (.ip.shown).
The sign-in page
Put .login-page on the body and a form.login in it: a title, a .lead line, the fields, a btn primary block and a .note under it.
