Buttons

Buttons, icon buttons, links, segmented controls, menus, the floating button and spinners.

ButtonsBusy buttons and spinnersIcon buttonsButtons that look like linksSegmented controlsMenus without codeCopy buttons

Buttons

.btn is a plain button. .primary is the page's main action (in the text colour; with a tone, in that colour: btn primary blue), .ghost has no border, .danger is for something that can't be undone. .sm is smaller, .round fully rounded, .block full width.

A link can look like a button too: <a class="btn" href="…">.

Busy buttons and spinners

Dash.busy(button, work) disables the button and puts a spinner before its label until work (a function or a promise) is done, and returns its result. It sets aria-busy="true", which is what draws the spinner. .btn.busy spins the button's own icon instead (an svg, or one with .spin). .spinner is a loading ring on its own; .spinner.lg is bigger, and a tone colours it.

Icon buttons

.icon-btn is a 28 px square button for an icon. Give it an aria-label (or a title) to say what it does. With aria-expanded its chevron turns; .danger turns it red on hover.

Buttons that look like links

.link is a button styled as a link, for an action inside text ("Show all"); .link.quiet is muted until hovered.

Segmented controls

.seg is a row of buttons where one is chosen. Dash.seg(el, { value, store, onChange }) runs it: buttons with data-value, aria-pressed on the chosen one, the choice remembered under store. It returns { value, set(v) }. A span in a button holds a count. Links with aria-current="page" make it a row of views instead. .seg.lg is for views in a top bar, .seg.solid a bordered look.

Menus without code

A <details class="menu"> with a summary (styled as a button) and a .menu-list of buttons and links is a menu with no script of your own. It closes on a click outside, on Escape and once an item is chosen. The list takes <hr> lines and .menu-label headings, and a tone on an item colours it. .menu.end opens to the left. Inside a table that scrolls sideways the list would be cut off: use Dash.menu there, which floats above everything.

Copy buttons

Any button with data-copy="text" copies the text when pressed, shows "Copied" in a toast (not with data-quiet) and says so on itself for a moment (.copied). Dash.copyButton(text, label) writes one; Dash.copy(text) copies from code and returns true or false (it works on plain-HTTP pages too).
